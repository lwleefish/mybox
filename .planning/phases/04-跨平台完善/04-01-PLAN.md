## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub Actions workflow → 第三方 action | 外部维护代码在 CI runner 上以仓库权限执行（供应链边界） |
| workflow → 探针二进制 | CI 循环以 shell 拼接注入 check 名，探针以 args[1] 分发 |
| 探针 → 系统剪贴板（enter_clipboard） | 真实 arboard 打开系统剪贴板（CI 会话能力不定） |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
