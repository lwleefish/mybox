## Phase Goal

**As a** mybox 用户，**I want to** 在命令面板中输入关键词即时过滤、用方向键与回车选择并执行命令，**so that** 所有工具通过键盘即可触达——面板成为真正的统一交互入口（PAL-03/PAL-04/PAL-05）。

<objective>
在 03-01 的「唤出窗口 + 命令列表」基础上叠加第二条垂直切片：**模糊搜索（fuzzy-matcher + 高亮）→ 键盘导航（↑/↓/回车/ESC）→ 命令执行生命周期（面板保持到完成/失败提示）→ 端到端验证**。纯逻辑（filter/session 状态机/execute）全部 headless 单测；真实窗口行为走 03-02 Task 3 的子进程-per-check `#[ignore]` 集成测试 + 手动清单（Phase 2 验证模式）。

Purpose: 把 PAL-03/PAL-04/PAL-05 的验收全部闭环，含用户最关注的截图时序边界（面板先隐藏再触发截图）与 Phase 2 re-entrancy 教训的泛化（generation 守卫）。
Output: filter.rs + execute.rs 新增；session/ui/lib 扩展；palette_checks bin + integration + manual_checklist；全 workspace 测试健康（含 mybox-test Pitfall 7 复检与 Windows check）。

⚠ **03-01 交付基线**（本 plan 依赖，直接使用）：`mybox_core::Command/CommandRegistry/run_command`；`WindowSpec.on_event_win`；`PaletteSession`（六态字段已声明，summon/close/set_window_id/generation/ensure_winit_state/take_focus_request 已实现）；`ui::draw`（卡片+输入框+Idle 全列表渲染）；`raster::paint`；`build_window_spec`（pub）。本 plan 不得重写 03-01 的已测逻辑，只做增量扩展。
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| 键盘/文本输入 → 过滤逻辑 | 用户任意输入进入 filter 与 egui 渲染，需限制成本与注入面 |
