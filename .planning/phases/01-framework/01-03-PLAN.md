# PLAN 01-03: 热键管理器 + 系统托盘 + 配置中心

## Overview

实现三个面向系统/持久化的服务：HotkeyManager（FRMW-04：全局热键注册 + id→action 映射）、ConfigCenter（INFRA-01：分节 TOML 读写 + 模块命名空间隔离；INFRA-04：用户目录存储；D-10/12/13）、TrayManager（INFRA-02：托盘驻留 + 动态菜单）。本 plan 与 01-02 并行（同为 Wave 2），热键/托盘/配置均可在无显示环境单元测试（真实注册与托盘构建属 01-04 集成/手动验证）。

**关键 research 决策（本 plan 锁定）：**
1. **D-11 无需自写解析器**（RESEARCH §0.4/§2.4）：global-hotkey 0.8 的 `HotKey: FromStr`，配置字符串 `"Cmd+Shift+T"` 直接 `.parse::<HotKey>()`。
2. **配置分节命名**（RESEARCH §11 #5 + §2.6）：顶层 `[hotkeys]` + 每模块 `[module_id]` 命名空间。首次启动文件布局在本 plan 明确固化。
3. **托盘图标运行时生成**（RESEARCH §2.5 + §11 #4）：tiny-skia 绘制单色 bitmap → `tray_icon::Icon::from_rgba`，不捆绑 PNG 资源。
4. **全局热键 manager 必须在主线程创建**（RESEARCH §2.4 macOS note）：本 plan 提供 `HotkeyManager::init(...)` 供 01-04 的 main 线程调用。

| ID | Threat | Severity | Mitigation (in this plan) |
