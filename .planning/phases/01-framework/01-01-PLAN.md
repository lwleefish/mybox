# PLAN 01-01: Workspace 骨架 + 核心类型定义

## Overview

建立 cargo workspace 骨架并定义 mybox-core 的全部核心数据类型：`Module` trait、`Event`/`EventFilter`、`WindowSpec`/`WindowKind`、`MyboxError`、`Renderer` trait、配置路径契约。这些类型是 01-02（事件总线+窗口管理器）、01-03（热键+托盘+配置）、01-04（事件循环集成+测试模块）的基础，本 plan 全部可在无显示环境的隔离中编译与测试。

**关键 research 决策（本 plan 锁定）：**
1. **egui 不进 Phase 1** — RESEARCH §5 证实 `egui-tiny-skia` 不存在于 crates.io。Phase 1 Renderer 是纯 tiny-skia；`Renderer` trait 的 `draw()` 闭包设计为 Phase 3 egui 层预留插槽。
2. **版本精确锁定**（RESEARCH §1）：winit 0.30.13、tiny-skia 0.12.0、softbuffer 0.4.8、global-hotkey 0.8.0、tray-icon 0.24.2、muda 0.19.3、crossbeam-channel 0.5.16、toml 1.1.4、directories 6.0.0。
3. **crossbeam-channel**（RESEARCH §7）作为事件总线 channel 实现。
4. **WindowId = u64 自增计数器**（RESEARCH §11 #6）。
5. **配置路径契约**：`directories::ProjectDirs::from("", "", "mybox")` → macOS `~/Library/Application Support/mybox/config.toml`（INFRA-04）。
